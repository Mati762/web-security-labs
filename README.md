# Web Security Labs & Write-ups

### Środowisko testowe
* **System:** Kali Linux (maszyna wirtualna VirtualBox)
* **Narzędzia:** Burp Suite Community Edition, cURL
* **Poligony:** OWASP Juice Shop (uruchamiany lokalnie w Dockerze)
